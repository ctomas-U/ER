# 樱花园 — Jardín de cerezos con carta

- `index.html` estructura · `style.css` estilos · `script.js` flores y carta
- El texto de la carta se edita en el objeto `carta` al inicio de `script.js`.
- `fonts/noto-serif-sc.woff`: Noto Serif SC (licencia SIL OFL) recortada a
  ASCII + los 3755 caracteres chinos más comunes (GB2312 nivel 1).
  No se usa ningún recurso externo, así que funciona en China.
